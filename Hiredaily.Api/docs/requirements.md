# Functional Requirements

- The system must allow user to provide their basic details and register them in the system
- The sytem must allow companies to register with their basic details.
- The system must allow employers to post jobs.
- The system must match jobs to workers based on criteria.
- The system must allow workers to apply.
- The system must allow the employer to select one worker.
- The system must notify the selected worker.
- The system must allow the worker to accept or reject.
- The system must lock the wage on acceptance.
- The system must release the wage after confirmation.
- The system must support dispute handling.

# Non-Functional Requirements

- Matching latency should be less than a few seconds.
- The system must handle concurrent job applications.
- The system must ensure only one worker is assigned.
- The system must be fault-tolerant.
- The system must support eventual consistency.
